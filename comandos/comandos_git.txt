git init . -> cria um repo git na pasta atual
git status -> mostra status do trabalho (de cada arquivo)
git add nome_arquivo -> adiciona arquivo para ser commitado
git commit -m -> faz commit do que estava para ser commitado
git log - > mostra todo o histórico de commit

### Fluxo de trabalho:

1. criar diretório (pasta) do projeto
2. iniciar git dentro do diretório criado (git init .)
3. git status
4. git add <nome arquivo>
5. git commit -m "mensagem"
6. voltar passo 3.
